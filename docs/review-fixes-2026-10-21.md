## Compatibility and data size

Schema version remains 2. The new `conversations.ranking` array is optional when restoring older summaries, so existing v1/v2 reports can still open. New reports keep the complete selected ranking and continue to retain the compact Top-20 lists for highlights. Large reports may exceed localStorage capacity or the 20 MiB summary import cap; the existing explicit errors apply.

Version 1 migration adds one migration notice to the known original warning count. Because v1 did not retain individual warning details, its original warnings are represented by a counted summary rather than invented messages.
