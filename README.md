# ChatGPT Wrapped

**中文** | [English](README.en.md)

把你的 ChatGPT 聊天记录，变成一份属于自己的年度报告。

[**在线生成你的报告 →**](https://systina12.github.io/ChatGPT-Wrapped/)

![ChatGPT Wrapped 年度报告预览：紫色背景、荧光绿图形与消息总数](docs/images/report-preview.png)

## 怎么使用

1. 在 ChatGPT 打开 **设置 → 数据控制 → 导出数据**，下载官方导出包。
2. 打开上方网站，选择 ZIP 文件，或选择解压后的完整文件夹。
3. 查看数据总览，进入年度报告；也可以调整年份、时区和统计范围，再生成分享卡。

[ChatGPT 官方导出说明](https://help.openai.com/en/articles/7260999-how-do-i-export-my-chatgpt-history-and-data)

## 报告里有什么

- **14 页年度回顾**：活跃时间、连续使用、常用模型、关键词、最长对话、附件与收藏等。
- **自由选择统计范围**：具体年份或日期区间、消息角色、对话分支，以及是否包含群聊。
- **年度比较与完整统计**：查看上一年变化，也能展开排行、图表和解析提示。
- **本地分享卡**：生成 SVG 或 PNG，标题和关键词由你决定是否加入。
- **中英文界面**：支持手机浏览、键盘操作和减少动画偏好。

## 数据留在你的设备上

聊天文件在浏览器本地处理，不会上传到服务器。没有账号、后台分析或远程字体。

只有点击“保存到本地”才会把报告保存在当前浏览器，也可以随时清除。分享卡默认只含汇总指标；下载报告 JSON 前会提醒其中可能含有标题、关键词和消息摘录等敏感内容。

## 大文件与报告文件

原始 ZIP 和文件夹导入不设固定体积门槛。程序只按需读取聊天相关 JSON，不解压图片、音频等附件；可处理的规模取决于设备内存，导入时可以取消。

单独导入已生成的**汇总报告 JSON**支持最大 20 MiB。汇总文件可以查看和制作分享卡；需要重新筛选时，请导入原始 ZIP 或文件夹。文件夹选择的支持情况因浏览器而异，不支持时使用 ZIP 即可。
